# MazePlace (A-Level NEA original)

This is my A-Level Computer Science NEA project exactly as I submitted it (late 2023/early 2024).
It's kept unchanged as a snapshot of my code from back then.

It's a 3D maze generator and solver built in Unity:

- **Generators:** recursive-backtracker DFS, Kruskal's, Wilson's
- **Solvers:** DFS, greedy best-first search

## Opening it

- Unity **2022.3.9f1**
- Install **Adobe Substance 3D for Unity** into `Assets/Adobe/`. The wall materials need it, but it isn't redistributed in this repo.
